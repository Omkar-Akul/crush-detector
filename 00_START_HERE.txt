🚀 QUICK START (5 Steps - 15 Minutes)
================================================================================

STEP 1: Create Database
  $ createdb crush_detector_db
  $ createuser crush_user  (password: your_password)
  $ psql -U crush_user -d crush_detector_db -f DATABASE_SCHEMA.sql

STEP 2: Setup Backend
  $ mkdir -p backend && cd backend
  $ cp ../backend_package.json package.json
  $ npm install
  
  Create .env file with:
    DB_HOST=localhost
    DB_USER=crush_user
    DB_PASSWORD=your_password
    DB_NAME=crush_detector_db
    JWT_SECRET=any_random_string_32_chars_long
    PORT=5000
    NODE_ENV=development
    CORS_ORIGIN=http://localhost:3000

STEP 3: Setup Frontend
  $ cd ../frontend
  $ npx create-react-app .
  $ cp ../App.jsx src/App.jsx
  $ cp ../App.css src/App.css
  $ cp ../frontend_package.json package.json
  $ npm install
  
  Create .env file with:
    REACT_APP_API_URL=http://localhost:5000

STEP 4: Run Backend
  $ cd backend
  $ npm start
  (Server will start on http://localhost:5000)

STEP 5: Run Frontend
  $ cd frontend
  $ npm start
  (Browser will open http://localhost:3000)

❓ COMMON QUESTIONS
================================================================================

Q: How do mutual crushes get detected?
A: Database triggers automatically create a match when two users declare
   interest in each other. Check DATABASE_SCHEMA.sql for the trigger code.

Q: Can I customize the styling?
A: Yes! Edit colors in App.css in the :root { } section. All colors use
   CSS variables for easy customization.

Q: How do I deploy to production?
A: Follow SETUP_AND_DEPLOYMENT_GUIDE.md section 8. Supports Heroku, AWS,
   Vercel, Netlify, and more.

Q: Is my password secure?
A: Yes! Passwords are hashed with bcrypt (10 rounds). They're never stored
   in plain text or logged.

Q: How do I backup my database?
A: Run: pg_dump -U crush_user crush_detector_db > backup.sql
   See SETUP_AND_DEPLOYMENT_GUIDE.md section 10 for more details.

Q: How do I add new features?
A: 1. Add database changes to DATABASE_SCHEMA.sql
   2. Add API endpoints to server.js
   3. Add UI components to App.jsx
   See README.md for future enhancement ideas.

================================================================================
🚨 TROUBLESHOOTING
================================================================================

Cannot connect to database?
  → Check PostgreSQL is running
  → Verify username and password in .env
  → Ensure database exists: createdb crush_detector_db

CORS error in browser?
  → Check CORS_ORIGIN in backend .env matches frontend URL
  → Restart backend server
  → Clear browser cache

API endpoint returning 401?
  → Token might be expired
  → Clear localStorage and re-login
  → Check JWT_SECRET matches

Frontend not loading?
  → Check npm start in frontend directory
  → Clear node_modules: rm -rf node_modules && npm install
  → Check .env file exists with API_URL

See SETUP_AND_DEPLOYMENT_GUIDE.md section 9 for more solutions.
